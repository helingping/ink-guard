# 墨卫 MVP 策划案

清洁室原型。名称用「墨卫 / Ink Guard」，字令用刀、枪、弓、骑，被保护的人是阿斗，来敌叫墨寇。不使用商业小游戏的标题、文案或素材。

## 核心循环

1. 开局有一笔馒头。点「招募」花掉馒头，随机得到一枚一品字令，落到下方席位。
2. 每成功招募一次，下一次更贵。
3. 把两枚**同一种、同一品**的字令叠在一起，目标那枚品级 +1，来源消失。最高四品，四品不能再合。
4. 把字令拖进 5 列 × 3 行的阵上才会攻击。拖回席位可以撤回。
5. 阵上的字令自动打射程内最近的墨寇。墨寇沿河道折线走向「斗」印，走到终点就扣阿斗气血。
6. 五波都清完，而且阿斗气血仍大于 0，胜利。气血到 0，失败。

馒头还会慢慢涨：每秒固定收入、击破一只墨寇、清完一波。这样循环不会在第一次招募后停住。没有广告，也没有付费。

## MVP 范围

做：

- 单机、一块棋盘、脚本波次。
- 四种字令，一到四品。
- 招募、合成、上阵、自动攻击、阿斗气血、胜负和重开。
- 数值全部来自 JSON，改表不用改代码。

不做：

- 玩家对战。概念图里上下两座棋盘是以后的对阵草图，这版只用下方这一座阵。
- 真实广告、内购、登录、排行榜。
- 微信小游戏出包（工程按 Creator 3.8 预览来做，没有 AppID）。
- 墨寇寻路、挡路、远程反击。
- 正式序列帧。刀枪弓骑用 Label 写字，印章和河道用 Graphics 画。

## 操作

- 点「招募」。馒头不够或 8 个席位已满时，底部提示原因。
- 按住字令拖动。松手时：
  - 靠近另一枚同字同品：合成。
  - 靠近空格子：上阵或换位。
  - 靠近空席位：撤回。
  - 字令不同或品级不同：弹回，并提示合不了。
- 拖动时显示该字令的射程圈。前排靠河道，一品后排大多打不到。
- 右上角「常速 / 三倍」只加快模拟，方便看完五波。

## 胜负

- 胜：`waves.json` 里的每一波都已出完，场上没有存活墨寇，阿斗气血 > 0。
- 败：阿斗气血 ≤ 0。漏掉的墨寇按该波的 `damage` 扣血，只扣一次。
- 波与波之间有 `gapSeconds` 秒。第一波之前有 `firstDelay` 秒，用来招募和上阵。

## 坐标

`board.json` 用画布中心为原点，**y 轴向上**，单位是像素。设计分辨率 720×1280。`units.json` 的 `range` 就是这个坐标系里的距离。

界面大致占用：

- y > 380：标题、波次、阿斗血条、馒头和招募。
- y < -560：底部提示。
- 河道折线、5×3 格子和 8 个席位都在两者之间。

格子索引从左到右、从上到下。第 0 行最靠近河道。

## 数值表

加载器会检查字段。缺字段或类型不对时，画面停在「配置没有读出来」，并写明是哪一个文件。

招募花费：

`recruitCostBase + recruitCostGrowth × 已经成功的招募次数`

当前是 `15 + 5 × n`，所以连续招募为 15、20、25、30……

### `ink-guard/assets/resources/configs/economy.json`

| 字段 | 现在 | 含义 |
| --- | --- | --- |
| startMantou | 140 | 开局馒头 |

| recruitCostGrowth | 5 | 每多招募一次，价格增加这么多 |
| incomePerSecond | 5 | 每秒馒头 |

## 代码落在哪

| 模块 | 文件 |
| --- | --- |
| 读 JSON | `ink-guard/assets/scripts/config/ConfigService.ts` |
| 校验 | `ink-guard/assets/scripts/config/validateConfig.ts` |
| 招募、合成、波次、战斗 | `ink-guard/assets/scripts/logic/GameSim.ts` |
| 格子和折线 | `ink-guard/assets/scripts/logic/geometry.ts` |
| 画面 | `ink-guard/assets/scripts/GameApp.ts`、`view/InkWidgets.ts` |

`GameSim` 不引用 Cocos。`ink-guard/tools/simulate.ts` 用同一套规则做无头回放：什么都不做会输；只铺一品、不合会在后几波输掉；会合成的打法能打完五波。
