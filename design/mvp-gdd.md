# 墨卫 MVP 策划案

清洁室原型。名称用「墨卫 / Ink Guard」，字令用刀、枪、弓、骑，被保护的人是阿斗，来敌叫墨寇。不使用商业小游戏的标题、文案或素材。

## 核心循环

南北对墨，不是单向的短河道塔防。北营出墨寇，沿三条贴着河道白痕的墨路南下；玩家在南岸布阵，字令向北出力。双方互相打得到：字令打墨寇，墨寇也打阵上的字令。漏到南端「斗」印才扣阿斗气血。

1. 开局有一笔馒头。点「招募」花掉馒头，随机得到一枚一品字令，落到下方席位。
2. 每成功招募一次，下一次更贵。
3. 把两枚**同一种、同一品**的字令叠在一起，目标那枚品级 +1，来源消失。最高四品，四品不能再合。升品后轮廓变大，墨圈变多，四品带金圈，不看文字也能分出品级。
4. 把字令拖进 5 列 × 4 行的南岸阵上才会攻击。前排近战，后排弓。拖回席位可以撤回。
5. 阵上的字令自动打射程内最近的墨寇。墨寇从北营出发，沿西墨、中渡、东墨三条弯路汇入同一个浅滩，再南下到「斗」印。
6. 五波都清完，而且阿斗气血仍大于 0，胜利。气血到 0，失败。

馒头还会慢慢涨：每秒固定收入、击破一只墨寇、清完一波。这样循环不会在第一次招募后停住。没有广告，也没有付费。

## MVP 范围

做：

- 单机、一块棋盘、脚本波次。
- 四种字令，一到四品。
- 招募、合成、上阵、自动攻击、阿斗气血、胜负和重开。
- 数值全部来自 JSON，改表不用改代码。

不做：

- 玩家对战。概念图里上下两座棋盘仍不是双人。这一版把那张图收成单机的南北对墨：北营出兵，南岸布阵，河道是双方相遇的浅滩。
- 真实广告、内购、登录、排行榜。
- 微信小游戏出包（工程按 Creator 3.8 预览来做，没有 AppID）。
- 墨寇寻路、挡路。墨寇会沿河道反击阵上的字令：近战挥到就打中，远程用和弓相同的弹道速度。
- 正式序列帧以外的新管线。刀枪弓骑、印章、河道和按钮用从概念图切出的 Sprite。墨寇用同一套攻击帧偏移，特效复用刀、枪、弓。射程圈仍用 Graphics。

## 操作

- 点「招募」。馒头不够或 8 个席位已满时，底部提示原因。
- 按住字令拖动。松手时：
  - 靠近另一枚同字同品：合成。
  - 靠近空格子：上阵或移动。
  - 靠近空席位：撤回。
  - 字令不同，或品级不同：交换两格的位置。
  - 已经是最高品还叠在一起：弹回，并提示已是最高品。
- 拖动、点选或悬停时，按 `units.json` 里该品的 `range` 画射程圈，并高亮圈内格子和墨路上的点。拖动时另外高亮合法落点（空位、合成、换位）。点空棋盘、点另一处界面，圈会收起。再点另一枚字令，圈挪到新的那枚上。鼠标和触摸都走同一套点按。
- 站位要分前后。一品刀、骑在前排够得到浅滩和「斗」印，够不到北营出口；二排刀够不到浅滩。一品枪在二排够得到浅滩。一品弓在后排盖得住浅滩和河道高处，前排的弓才够得到北营出口。后排的刀和枪打不到任何一条墨路。
- 第一次进入会在席位放两枚「刀」，并显示合成说明。合成一次之后不再出现。
- 右上角「常速 / 三倍」只加快模拟，方便看完五波。

## 胜负

- 胜：`waves.json` 里的每一波都已出完，场上没有存活墨寇，阿斗气血 > 0。
- 败：阿斗气血 ≤ 0。漏掉的墨寇按该波的 `damage` 扣血，只扣一次。
- 波与波之间有 `gapSeconds` 秒。第一波之前有 `firstDelay` 秒，用来招募和上阵。现在是 12 秒。

## 坐标

`board.json` 用画布中心为原点，**y 轴向上**，单位是像素。设计分辨率 720×1280。`units.json` 的 `range` 就是这个坐标系里的距离。

界面大致占用：

- y > 360：标题、波次、阿斗血条、馒头和招募。
- y ≈ 312：北营「寇」印。
- y ≈ 86：河道贴图。三条墨路的白痕贴在这张图的浅色中线上。
- y ≈ -8：南端「斗」印，三条墨路汇合。
- 其下是 5×4 南岸。第 0 行 y = -78，最靠近浅滩。席位在 y = -424。
- y < -560：底部提示。

格子索引从左到右、从上到下。第 0 行是前排。

## 数值表

加载器会检查字段。缺字段或类型不对时，画面停在「配置没有读出来」，并写明是哪一个文件。

招募花费：

`recruitCostBase + recruitCostGrowth × 已经成功的招募次数`

当前是 `15 + 5 × n`，所以连续招募为 15、20、25、30……

### `ink-guard/assets/resources/configs/units.json`

`order` 决定招募抽签顺序，四项等概率。`aspd` 是每秒攻击次数。`range` 是像素射程。`hp` 是字令气血，只会被墨寇打掉，合成后按新品级回满。`ink` 是印章颜色。`style` 是 `melee` 或 `ranged`：近战在 `strike` 秒后打中，不看弹道速度；远程以 `shotSpeed` 像素/秒飞出弹道。`motion` 每种字令各不相同，用来区分斩、刺、射、冲。

墨寇在 `foes.json`。`vfx` 指向一种字令：`style`、`motion`、`strike`、`shotSpeed` 和一品 `range` 都从那条字令抄过来。寇接刀，矛接枪，矢接弓。矢因此会射出和弓一样的箭。波次 `roster` 决定这一波按什么顺序出这些字。

### 站位（第 5 条）

南岸 5×4。第 0 行贴着浅滩，是前排。

- 北营出口只在前排弓的射程里。一品刀、枪、骑都打不到还站在出口的墨寇。
- 河道高处（西侧波峰）后排弓够得到，前排刀够不到。
- 浅滩：前排刀够得到，二排刀够不到；二排枪够得到。
- 后排的刀和枪到任何一条墨路都差一截。

所以开局要把刀和骑推到前排顶住渡口，枪放第二排，弓留在后排先手。墨寇的近战射程抄刀和枪的一品，只能打到前排附近；矢抄弓的一品射程，从河道上就射得到后排。前排挨打、后排对射，两边才合作得起来。

### 南北对墨（第 6 条）

仍是单机守阿斗，不是双人对战，也不借用任何商业角色的名字或立绘。

- 北：`camp` 是「寇」印，三条墨路从这里出发，向南。
- 中：`river` 是河道贴图。西墨从西岸贴着白痕走到浅滩，东墨从东岸贴回来，中墨先弯到同一处波峰再汇入浅滩。三条路的水平段用的是河道贴图里那条浅色中线，不是另外画一条穿过水色的折线。
- 南：5×4 的阵，终点是「斗」印。墨寇走到这里扣一次气血，同时会打射程内的字令。

压力是对向的：你往北打，他们往南走，走到脸前才轮到近战。中墨较短，是先到的渡口；东西两墨绕河道，给后排弓更长的输出时间。

## 代码落在哪

| 模块 | 文件 |
| --- | --- |
| 读 JSON | `ink-guard/assets/scripts/config/ConfigService.ts` |
| 校验 | `ink-guard/assets/scripts/config/validateConfig.ts` |
| 招募、合成、波次、战斗 | `ink-guard/assets/scripts/logic/GameSim.ts` |
| 格子和折线 | `ink-guard/assets/scripts/logic/geometry.ts` |
| 画面 | `ink-guard/assets/scripts/GameApp.ts` 绑定 `main.scene` 里的节点。`view/InkWidgets.ts` 只留颜色和射程圈 |

HUD、棋盘槽位、招募、倍速和胜负面板在 `main.scene` 里用 Canvas、Widget、Button、Label、Sprite、Layout 摆好。`GameSim` 不引用 Cocos。`ink-guard/tools/simulate.ts` 用同一套规则做无头回放：什么都不做会输；只铺一品、不合会输掉；会合成的打法能打完五波。异种或不同品级的字令交换位置，不再合成失败。
